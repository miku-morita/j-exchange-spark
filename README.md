# J-EXCHANGE SPARK 管理アプリ

起動：`python -m streamlit run app.py`

公開・アップデートの手順は [DEPLOYMENT.md](DEPLOYMENT.md) を参照してください。現在のCSV保存はローカル・デモ用であり、本運用には外部データベースへの移行が必要です。

## 画面

- ホーム：次回の活動、未回答の出欠、回答期限。
- シフト：自分の回答の確認・変更。プロフィールとは別に保存。
- 予定：日付順の活動一覧。過去の活動は折りたたみ表示。
- マイページ：基本情報の確認・編集。
- 管理：管理者専用。回答一覧、名簿、日程登録・削除、メンバー削除。メンバー登録・権限変更・パスワード再設定は従来どおり統括専用。

日常連絡・正式なお知らせはDiscord、資料保管はGoogle Driveを利用します。通知の自動送信は未実装です。

## データの互換性

既存の3つのCSVを利用します。日程を新規登録すると `target_dates.csv` に `活動日`（YYYY-MM-DD）と任意の `回答期限` 列が追加されます。既存行やシフト回答のキーである `日程` は変更しません。

年のない既存日程は「活動年を確認する日程」に月日順で表示し、次回の活動とは判定しません。既存日程の年が確認できたら、バックアップを取ったうえで `活動日` 列を補完してください。日程文字列を変更すると既存回答との対応が失われます。

回答期限は日本時間の日付単位です。期限後も回答を保存でき、締め切りによる入力制限は設けていません。参加回答は確定シフトの割当ではありません。

## 統括ログインの設定

固定の代替パスワードによるログインは無効化しました。統括ログインにはStreamlitのSecretsで `SUPER_ADMIN_PASS` の設定が必要です。ローカルではプロジェクト内の `.streamlit/secrets.toml` **ファイル**に設定します。プロジェクト直下の `secrets.toml` **ディレクトリ**はこの標準設定先ではありません。実際の秘密値を共有・コミットしないでください。

## 動作確認

`python -m py_compile app.py test_app.py`

`python -m unittest test_app -q`

テストは一時フォルダの架空データを使用します。ログイン、初回パスワード変更、プロフィールとシフトの独立保存、日程登録、権限取り消し、一般メンバーの管理画面アクセス制限、統括の各画面、空の日程を確認します。

手元ではスマートフォンの表示、実際のSecrets設定、統括によるメンバー登録・アカウント変更・削除を確認してください。削除操作の確認には必ず架空データを使用してください。

## 今後見直す点

- パスワードはソルトなしのSHA-256で保存されており、認証専用のハッシュ方式への移行が必要です。
- シフト回答はメールアドレスや固定IDではなく名前で識別され、同姓同名の回答が混在・上書きされる可能性があります。
- CSVへの直接保存には排他制御がなく、複数人の同時保存やDropbox同期によって更新が失われる可能性があります。
- 管理者は居住地などを含む名簿を閲覧でき、通常の管理者もメンバー削除ができます。今回は従来の権限範囲を維持しています。
- ログイン試行回数制限、セッション有効期限、個人情報の保存・バックアップ方法は未整備です。
